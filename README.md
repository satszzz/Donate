# 🍲 Food Donation Management System

A web-based platform that connects food donors, NGOs, and receivers to reduce food waste and help people in need.

## 📌 Project Overview

The Food Donation Management System enables:

- Donors to donate excess food
- NGOs to manage and distribute donations
- Receivers to request food assistance
- Easy communication between stakeholders

## ✨ Features

- 👤 User Login System
- 🍱 Food Donation Registration
- 🤝 Donor & Receiver Management
- 🏢 NGO Dashboard
- 📱 Responsive Design
- 🔒 Secure User Access

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Tailwind CSS
- Node.js
